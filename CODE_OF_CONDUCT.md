# Code of Conduct

Be decent. That is the whole of it.

- Assume good faith. People are often working through something.
- Criticise the code, not the person who wrote it.
- No harassment, no slurs, no personal attacks.
- Keep discussions on the technical topic.
- If someone is being difficult, let the maintainers handle it.

This project follows the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.
