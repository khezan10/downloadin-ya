# Cara Mendapatkan RapidAPI Key - Social Download All In One

## Step 1: Buka Halaman API

Klik link ini: **https://rapidapi.com/nguyenmanhict-MuTUtGWD7K/api/social-download-all-in-one**

## Step 2: Daftar / Login RapidAPI

- Kalau belum punya akun, klik **"Sign Up"** (bisa pakai Google/GitHub)
- Kalau sudah, klik **"Log In"**

## Step 3: Subscribe ke API (GRATIS)

1. Setelah login, klik tombol **"Subscribe to Test"**
2. Pilih plan **BASIC ($0.00/mo)** - GRATIS
3. Klik **"Subscribe"**

## Step 4: Copy API Key

1. Setelah subscribe, klik tab **"Endpoints"**
2. Lihat bagian **"Header Parameters"** di sebelah kanan
3. Copy nilai dari **"X-RapidAPI-Key"**
   - Format: huruf dan angka panjang, contoh: `abc123xyz456...`

## Step 5: Kirim Key ke Saya

Setelah dapat key-nya, kirim di chat dan saya akan update website.
